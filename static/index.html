Transparence & données

Ce que nous ne faisons pas

  • • Pas de stockage de mots de passe.
  • • Pas de revente de données.
  • • Pas de tracking publicitaire.

Ce que nous collectons

  • • Jetons d’accès chiffrés en mémoire vive uniquement.
  • • Données de profil minimales (ID, région) pour l’affichage.
  • • Logs techniques anonymisés (erreurs, latence).

Vos contrôles

  • • Déconnexion instantanée (révocation des jetons).
  • • Suppression des caches locaux.
  • • Export / purge sur demande.

Conformité

  • • Respect RGPD (finalités claires, minimisation).
  • • Non-affiliation à Riot, respect des CGU.
  • • Code côté client priorisé quand possible.

Note : certains accès peuvent être restreints par Riot. Utilisez l’outil de manière responsable.

FAQ

Est-ce autorisé ?❓

Nous n’utilisons pas d’outils visant à nuire. Respectez les CGU de Riot. L’usage reste à votre discrétion.

Mes identifiants ?🔑

Votre mot de passe n’est jamais stocké. Les jetons d’accès expirent et ne sont conservés qu’en mémoire.

Performances⚙️

L’app est légère, met en cache quelques réponses et ne fait que le strict nécessaire.

Open-source ?💻

Une version publique est prévue. Vous pourrez auditer la collecte et contribuer.
